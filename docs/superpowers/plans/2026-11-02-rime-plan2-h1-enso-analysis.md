# rime Plan 2: H1 confirmatory ENSO analysis

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run the locked H1 tests (national H1-N and regional H1-R), the negative control, and the pre-specified H1 sensitivity analyses exactly as `prereg/hypotheses.md` (tag `prereg-v1`) defines them, and write the results plus a plain-language summary.

**Architecture:** New subpackage `rime.h1`. `panel.py` builds zero-filled monthly count panels from `events_aircraft.parquet` + `enso_monthly.parquet`. `models.py` fits the prereg models and returns effect estimates. `run.py` is the CLI step `h1`; it refuses to run unless the `prereg-v1` tag exists, then writes `results/h1/`.

**Tech Stack:** existing (pandas, numpy, scipy, statsmodels), plus `statsmodels.stats.multitest.multipletests` for Holm.

**Spec:** `docs/superpowers/specs/2026-11-02-rime-design.md`. **Binding:** `prereg/hypotheses.md` at tag `prereg-v1` (commit `18299e7`).

## Global Constraints

- The prereg is binding. Model formulas, families, test counts, α, tails, periods, tiers, and the season (Nov–Mar) are copied from it, never changed. Anything not in it is labeled exploratory in outputs.
- Primary periods: airliner 1997–2024; charter, ga_piston, ga_turbine, helicopter 2004–2024 excluding 2011. These come from `rime.power.study_years`; reuse it, don't re-derive.
- Outcome unit: aircraft involvements in accidents (`ev_type == "ACC"`). "Weather" = `wx_involved`. "Fatal" = the event's highest injury is fatal (the existing `fatal` column).
- H1-N family: 9 tests, i.e. 5 categories × {el_nino, la_nina} minus charter × la_nina. Two-sided. Holm, family-wise α = 0.05.
- H1-R family: 2 tests on ga_piston, winter months Nov–Mar. H1-Ra: southern tier = {southeast, south, southwest, west}, el_nino, share higher. H1-Rb: northern tier = {northwest, northern_rockies_plains, upper_midwest, ohio_valley}, la_nina, share higher. One-sided. Holm, α = 0.05.
- Phases: neutral is the reference. Lag 0 is primary.
- `results/h1/` files are regenerated by `uv run rime h1`. Nothing is hand-edited.

## Review Focus

1. **Category-months with zero events** must appear as rows with count 0, not be missing. Fixes deferred minor M4. Test in Task 1.
2. **Lag 3 crossing a year boundary:** January's lag-3 phase is the previous October's, even when the previous year is outside the study period or is 2011. The ENSO series is complete, so look it up there. Test in Task 1.
3. **NB fit failing to converge on a sparse category:** retry with `method="bfgs"`, then `"nm"`. If it still fails, report the test as `not_estimable` with p = 1.0 in the Holm step (conservative), never drop it silently. Test in Task 2.
4. **Super El Niño sensitivity:** months in super episodes become level `super_el_nino` and are *not* counted as `el_nino`. Test in Task 1.
5. **Running `rime h1` without the `prereg-v1` tag** must exit with an error message and write nothing. Test in Task 3.

### Task 2: Models and Holm

**Files:**
- Create: `src/rime/h1/models.py`
- Test: `tests/h1/test_models.py`

**Interfaces:**
- Produces: `@dataclass Effect(rr: float, ci_lo: float, ci_hi: float, p: float, n_events: int, status: str)`, where `status` ∈ {`ok`, `not_estimable`}. When not estimable: rr/ci are NaN and p = 1.0.
- Produces: `fit_h1n(panel: pd.DataFrame) -> dict[str, Effect]`.
  - Model: `smf.negativebinomial("count ~ C(phase, Treatment('neutral')) + C(year) + C(month)", panel)`, ML dispersion.
  - Fit with `method="newton"` first, then `"bfgs"`, then `"nm"` (maxiter 2000), taking the first that converges with finite SEs.
  - Returns one Effect per non-neutral phase level present (`el_nino`, `la_nina`, and `super_el_nino` when present). The p-value is a two-sided Wald test; the CI is a 95% Wald interval, exponentiated.
- Produces: `fit_h1n_original(panel: pd.DataFrame, hours: pd.Series) -> dict[str, Effect]`, for sensitivity 8.
  - `hours` is indexed by year.
  - Model: NB GLM (statsmodels `GLM`, `NegativeBinomial(alpha=α̂)`, where α̂ comes from `fit_h1n`'s dispersion), `count ~ C(phase) + C(month) + yc + yc²` (yc = year − mean), offset `log(hours/12)`, cluster-robust SEs by year.
- Produces: `fit_h1r(tier: pd.DataFrame, target: str) -> Effect`.
  - Model: binomial GLM on `(tier_count, rest_count)` over `C(phase, Treatment('neutral'))`, using rows with `tier_count + rest_count > 0`.
  - rr = exp(coef) is the odds ratio of the tier share. The p-value is **one-sided**, `norm.sf(z)`.
- Produces: `holm(effects: dict[str, Effect]) -> dict[str, tuple[float, bool]]`, mapping each key to (adjusted p, reject at 0.05). Uses `multipletests(method="holm")`.

- [ ] **Step 1: Write failing tests** (simulated panels, seed fixed):
  - `test_fit_h1n_recovers_rr`: 20 years × 12 months; Poisson mean 20 × year effect × RR 1.5 in El Niño months → El Niño rr within its CI, ci_lo > 1.2, ci_hi < 1.8. La Niña CI contains 1.
  - `test_fit_h1n_null_p_not_tiny`: RR 1 → both p > 0.001.
  - `test_fit_h1n_not_estimable_when_no_events`: all-zero counts → status `not_estimable`, p == 1.0.
  - `test_fit_h1r_one_sided`: tier share raised in El Niño → p < 0.01. Share lowered → p > 0.5 (one-sided, so the effect is in the wrong direction).
  - `test_holm_adjusts`: p {a: 0.01, b: 0.04} → adjusted {0.02, 0.04}, both reject.
- [ ] **Step 2:** Run `uv run pytest tests/h1/test_models.py -q`. Expected: FAIL.
- [ ] **Step 3:** Implement `models.py`. Silence statsmodels convergence warnings inside the retry loop only.
- [ ] **Step 4:** Run. Expected: PASS.
- [ ] **Step 5:** Commit `feat(h1): prereg models and Holm correction`.
