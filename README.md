# rime

A public data study asking whether changing weather patterns — long-term climate change and cycles like El Niño — have measurably changed aviation safety in the US. Named after rime ice, the rough ice that builds up on wings in supercooled cloud.

Everything is rebuilt from free public data with one command:

```sh
uv sync && uv run rime all
```
